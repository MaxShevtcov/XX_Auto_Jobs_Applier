# Learned Instincts

This directory stores atomic "instincts" — small learned patterns extracted from development sessions.

Each file is a YAML-instinct following the format from `.opencode/skills/continuous-learning/SKILL.md`.

## Naming

`YYYY-MM-DD--kebab-case-id.yaml`

## Lifecycle

1. Session work → `/learn` → instinct file created here
2. Accumulate 3+ related → `/evolve` → skill update proposed
3. Skill updated → instincts moved to `.opencode/learned/evolved/`
